Cara mengambil cookie Dapodik

  1. Login ke Dapodik di browser, mis. https://dapodik2.sekolah.sch.id. Gunakan akun/sesi khusus tool bila tersedia.
  2. Buka Developer Tools: tekan F12 (atau klik kanan → Inspect), lalu pilih tab Network.
  3. Muat ulang halaman Dapodik (Ctrl+R / Cmd+R).
  4. Klik salah satu request ke server Dapodik (mis. PesertaDidik atau halaman utama).
  5. Di panel kanan, buka Headers → Request Headers, cari Cookie.
  6. Salin seluruh nilai Cookie, bukan hanya PHPSESSID. Biasanya termasuk PHPSESSID, killme, dapodik_rememberme, dapodik_username, dapodik_password, dan cf_clearance jika ada.
  7. Tempel ke field Cookie Dapodik, klik Simpan scope.
  8. Klik Tes koneksi. Jika muncul Session telah habis, ulangi dari langkah 1 atau pastikan cookie tidak terpotong.
{{icon "alert"}} Cookie adalah kunci sesi Dapodik. Jangan mengirimnya ke chat/email dan jangan simpan di file publik. Jika cookie disimpan di scope ini, jangan logout dari sesi Dapodik tersebut. Gunakan akun/sesi khusus tool bila tersedia.
Catatan Cloudflare, kedaluwarsa, dan enkripsi
  • cf_clearance dapat terikat pada IP/User-Agent. Jika Dapodik memakai Cloudflare dan server tool memakai IP berbeda, cookie bisa ditolak.
  • Cookie Dapodik punya masa berlaku. Jika job gagal dengan Session telah habis, ambil cookie baru dan simpan ulang di scope yang sesuai.
  • Cookie/token disimpan terenkripsi AES-GCM. Kunci diturunkan dari CREDENTIALS_KEY atau SESSION_SECRET.
  • Mengubah CREDENTIALS_KEY/SESSION_SECRET membuat kredensial lama tidak bisa didekripsi; simpan ulang.
  • Operator hanya melihat scope yang di-assign admin; admin melihat semua scope.
